# Persistent AI Studio examples

These copy-paste scenarios show when the Skill is useful and what evidence a responsible result should expose. They are illustrative, not claims of production outcomes.

## Start a bounded product horizon

```text
Use $orchestrate-agent-organization to steward this open-source tool through one funded horizon: improve installation success and contributor readiness. Keep product decisions with me, size the organization from the real task graph, and stop after verified integration.
```

A useful run creates or reconciles one studio state, confirms the current charter, selects a finite milestone, records the capacity plan, delegates only independent work, and integrates verified changes without widening the mandate.

## Continue, pause, or retire from evidence

```text
Use $orchestrate-agent-organization to review this project's current horizon. Compare the promised outcome with usage, maintenance burden, unresolved risks and available capacity. Recommend continue, pause, pivot or retire, but do not execute a consequential decision without my authorization.
```

The portfolio recommendation should name the evidence window and its limits. Repository traffic, agent agreement, and configured tests must not be misreported as users, demand, or verified outcomes.

## Govern a cross-project improvement

```text
Use $orchestrate-agent-organization to improve documentation quality across these four repositories. Audit in parallel, keep writes serial unless workspaces are isolated, preserve unrelated changes, and require an independent final verification packet.
```

An illustrative audit trail contains:

```text
route: organized
topology: mission cell with independent assurance
parent charter: authorized
work items: bounded with acceptance criteria and consumers
integration: serial, provenance preserved
assurance: implementation author is not the final verifier
```

## When not to use it

Do not invoke a persistent studio for one short factual answer, a tightly sequential edit, or work with no ongoing product or portfolio decision. Use the smallest direct workflow instead.
