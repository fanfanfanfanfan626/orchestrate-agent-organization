# Support

Start with the [README](README.md), [AI installation contract](AI_INSTALL.md), [worked examples](EXAMPLES.md), and [compatibility evidence](COMPATIBILITY.md).

- File a **bug report** for a reproducible planner, validator, packaging, or instruction-contract failure.
- File a **feature request** for a concrete portfolio, organization, handoff, integration, or assurance gap.
- Use a regular Issue for non-sensitive documentation corrections and compatibility questions.

Include the release or commit, host and host version, available agent/context/workspace isolation, exact command or request with private details removed, and expected versus actual behavior. Never publish credentials, personal paths, studio state, proprietary product details, or private decision records.

Security-sensitive reports belong in the private channel described in [SECURITY.md](SECURITY.md).
