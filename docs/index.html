Open-source Agent Skill

Keep the product alive after the task ends.

Persistent AI Studio gives an AI lead a governed operating model for product work that spans tasks: portfolio choices, human authorization, right-sized agent teams, bounded permissions, independent assurance, and long-term ownership.

Install the SkillInspect the system

One lifecycle, not a temporary org chart.

01Discover

Clarify the product and preserve the choices that still belong to the human.

02Select

Fund a finite horizon using portfolio evidence instead of enthusiasm alone.

03Organize

Size roles and concurrency from the actual task graph and runtime limits.

04Assure

Separate proposal, deployment, and audit when the decision is material.

05Steward

Carry state, evidence, ownership, maintenance, and retirement across tasks.

Governance that remains executable.

Deterministic planners

Python and PowerShell tools validate studio state and select the smallest useful execution topology.

Bounded delegation

Every child receives an explicit charter, permission subset, context budget, lease, and write scope.

Human root authority

Material product, value, risk, and authorization gates remain with the human.

Lossless integration

Findings, dissent, operating obligations, and evidence survive final synthesis.

One-prompt install

Give the repository to your agent.

Install orchestrate-agent-organization from https://github.com/fanfanfanfanfan626/orchestrate-agent-organization. Read AI_INSTALL.md first, copy the complete nested skill directory, and verify the installation before reporting success.

Full organized execution needs subagent lifecycle tools and isolated workspaces. Compatible hosts without them use the same governance roles serially.

持久化 AI 工作室

任务结束，产品责任不能一起消失。

这个开源 Skill 为跨任务的产品工作提供组合决策、人类授权、自动定规模的 Agent 组织、有限权限、独立保证和长期维护机制。它从真实工作出发，不用组织架构表演代替交付。
